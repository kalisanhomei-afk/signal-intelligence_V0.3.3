# SIGNAL V0.4.2｜證據品質與來源使用政策

| 證據級別 | 可取得內容 | 允許說明 | 禁止推論 |
|---|---|---|---|
| M0 | 標題、發布時間、發布機構、原始連結 | 可知道該來源發布了這個標題 | 不能聲稱完整研究結論、新聞真相或影響 |
| M0A（本版僅 arXiv） | 官方 arXiv API 送出的作者摘要元資料，已核對 ID + 標題 | 可識別作者自述的研究目的、方法與初步結果（應歸因作者） | 不可宣稱全文已查、經同儕審查、已重現、已商用或證實 |
| M1（未建立） | 合法取得並核對原始文件內容、關鍵數字與上下文 | 可以分析該來源真正寫了什麼 | 仍不得推論原作者主張已被獨立證實 |
| M2（未建立） | 獨立於原發布者、可核對的主要資料或查證報導 | 可進行主張級證據比較 | 單一機構多篇文章不計為多個獨立來源 |

## 嚴格限制
- 只讀取 arXiv 官方 Atom API 的摘要描述性元資料；不下載 PDF、程式附件或其他媒體的完整文章。
- arXiv 研究摘要由作者撰寫，因此「已取得作者摘要」與「主張已獲證實」完全不同。所有 `verified_claims=0`。
- 只有 `arxiv.org/abs/{ID}`、合法 ID、API 相同記錄 ID、與 RSS 標題正規化相符的候選，才標 M0A；其他仍 M0。
- API 失敗或回應中無法匹配標題 → 不升 M0A；記錄錯誤，不做臆測或偷改分數。
- 不能從 M0/M0A 計算可信度百分比、全球重要性分數、投資勝率。三個發布機構也不是全球資訊覆蓋。
- 報告不應寫「已完成跨來源驗證」；本版只是擴充原始證據。
