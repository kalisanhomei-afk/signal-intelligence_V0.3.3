# SIGNAL V0.3.4｜資料來源與驗收契約

**核心原則**：技術上可連線、內容可以儲存、證據可信、值得優先閱讀是四種不同狀態，不能合併為單一「已驗證」。

## 本階段限定用途

本期只發布 `descriptive_public_metadata_only`：
- 標題、來源、類別、時間、原始網址、RSS 通道與取得時間。
- 來源本人陳述不等於獨立驗證；預印本不等於同行評審。
- 不抓取第三方全文、圖片、PDF、評論；不以 AI 生成投資預測。
- 不使用 BLS／NASA JPL 回 403 端點，也不規避機器人限制。

## 四條來源／三個發布機構

| 通道 | 用途 | 公開權利條款 | 狀態 |
|---|---|---|---|
| `fed-monetary` | 貨幣政策公告 | https://www.federalreserve.gov/disclaimer.htm | 只發布描述性元資料 |
| `bea-news` | GDP、PCE 等官方公告 | https://www.bea.gov/help/faq/147 | 只發布描述性元資料 |
| `arxiv-ai` | AI 研究發現 | https://info.arxiv.org/help/api/tou.html | 只發布 CC0 描述性元資料 |
| `arxiv-robotics` | 機器人研究發現 | 同上 | 只發布 CC0 描述性元資料 |

這張表是從 37 家候選機構中**先行接入的很小一批**，不是完整新聞來源策略；新聞媒體、台灣、國際政治與產業專業機構仍在來源治理清單。公司聲明與研究發現須由 V0.4 在重大決策前進行獨立核對。

## 安全和可靠性

- 只能使用明確允許的四條 HTTPS 來源 URL；私自添加來源會使測試失敗。
- 每次來源連線只下載最多 2 MB；XML 禁止 DTD／entities，不能接受外部轉址到其他主機。
- arXiv 兩個 RSS 使用依序請求及至少 3 秒間隔，遵守 arXiv 官方存取節流。
- 來源錯誤會記錄成功數、最近一次成功時間、出錯原因；不將回傳空集合當作一定失敗。
- 只將權利已確認的來源**元資料**輸出到 `_site/data/discovered.json`；任何非允許來源、`summary` 內文都會觸發公開輸出拒絕。
- 由 GitHub 每天執行 2 次、更新 Git 儲存庫的 `data/live_items.json` 以保留 45 天歷史；Actions 使用 `GITHUB_TOKEN` 回寫資料不會自動觸發另一個 push 工作流程，故在同一次 workflow 直接執行 Pages 部署。
- 原本 2026-11-05 編輯樣本留在 `data/feed.json`，屬手工靜態內容；此階段尚不會自動產生今日情報或每週報告。
