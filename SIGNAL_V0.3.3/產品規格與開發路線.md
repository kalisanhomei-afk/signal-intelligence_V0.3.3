# 視界 SIGNAL｜個人情報暨投資研究系統

**決策版次：V0.2（2026-11-05）**　**使用對象：個人優先**　**顯示時區：Asia/Taipei**

## 一、產品定位

這不是新聞瀑布流，也不是未經驗證的「AI 預言股價」工具。最終目標是建立一條可追溯的決策資訊鏈：

**公開來源 → 原始資訊 → 事件整併 → 核驗與反向觀點 → 每日／每週／每月呈現 → 主題追蹤 →（經獨立驗收後）投資研究。**

三種價值獨立存在：全球重要性、個人相關性、盲點／探索價值。避免僅根據閱讀行為推送相似內容。

## 三、架構原則：兩條資料管線，避免污染

### A. 原始發現層（Unreviewed Discovery）
- 來源：RSS、官方公告、學術發布、授權 API。只保存標題、連結、來源、公開時間、抓取時間及來源種類。
- 狀態：`未審核標題`；禁止自動標示為「真實重大消息」。
- 去重：先用正規化 URL，再在下一階段使用事件／實體／時間範圍聚合。
- 不使用社群熱度直接決定全球重要性。

### B. 審核情報層（Editorial Intelligence）
- 欄位：事件 ID、事實摘要、已核實來源、可反駁的推論、反向觀點、時間戳記、領域、重要性理由。
- 僅經來源核對才可進入每日與每週精選；標示「已確認／推論／未確認」。
- 同一事件的不同媒體報導要保留多個證據，但呈現一個事件主軸。
- 每週抽查漏選：重大國際事件、冷門技術、非既有興趣領域。

## 四、後續實際開發階段與驗收關卡

| 關卡 | 工作 | 交付驗收（未通過不擴範圍） |
|---|---|---|
| **G1：來源管線** | 正式部署 RSS/官方日程更新、保存原始資料、錯誤日誌及來源健康度 | 至少 4 個不同來源成功連續更新；故障時保留舊資料並標出「過期／來源失效」；不同來源時間與網址正確 |
| **G2：情報評選** | 事件去重、AI 輔助摘要、證據引用、選題配比與不同觀點；加入人工快速覆核 | 以連續兩週樣本抽查：不可捏造事實、日期與來源；能追查原文；使用者認為每日 10–12 則具有足夠資訊密度 |
| **G3：日週月報** | 每日精選、每週跨事件分析、每月長期趨勢、追蹤時間軸、改期提醒 | 7 天資料連續可用，重複報導不反覆推送；不同期間內容具有獨立價值 |
| **G4：個人化與部署** | PWA、跨裝置同步（視需要）、提醒整合、保存個人回饋 | 手機／電腦可正常使用；隱私與 API 金鑰不曝露到前端；不推播重複與失效事件 |
| **G5：投資資料底座（獨立模組）** | 台股／美股／債券／商品／指數／期貨價格與法人行為、市場事件時間對齊 | 價格調整、除權息、匯率、休市日、債券與期貨契約規則正確；歷史修訂可重現 |
| **G6：預測研究** | 15、30、約 63 個交易日的情境概率；獨立樣本回測、基準比較 | 排除未來資訊洩漏、股票下市偏誤、樣本挑選偏誤；計入費用與滑價；風險評估達到預設門檻才上線 |

**優先順序：G1 → G2 → G3 → G4；市場分析只先保留欄位與接口，不妨礙情報主線。**

## 五、投資研究子系統設計（未來，但現在先預留資料模型）

### 研究範圍
- **台灣股票：** 股票、ETF、加權指數與相關產業；需處理除權息、企業行為與交易日曆。
- **美國股票：** 個股、產業 ETF、主要指數；需處理公司行為、時區、財報公布時點。
- **固定收益：** 美國公債、公司債、殖利率曲線；衡量**總報酬、久期與信用風險**，不能直接用殖利率漲跌代表投資績效。
- **商品與期貨：** 能源、金屬、農產品等；需處理連續契約構造、換月、展期收益、保證金、槓桿風險。
- **跨資產：** 匯率、利率與商品指數作為輔助變數，不預設所有資產共用同一模型。

### 每個投資標的基本資料
`asset_id`、市場、交易所、幣別、資產類別、公司／契約識別碼、交易時段、資訊可用時間、企業行為、原始價格來源及授權狀態。

### 三種獨立資料層
1. **資訊層：** 新聞、事件、公布時間、消息確信程度、預期 vs 實際、來源鏈結。
2. **市場層：** OHLCV、調整價格、利率、殖利率、企業財報、技術／基本面指標、交易成本。
3. **研究層：** 特徵、訓練時點、模型版本、回測區間、交易成本、預測分布、實際績效。

**禁止**把財務新聞的編輯重要性（如 92/100）直接當成股價上漲機率（如 92%）。這是兩種完全不同的測量對象。

### 三個預測持有期
- 15 交易日：偏向短期事件與部位風險。
- 30 交易日：觀察資料修正、財報／政策反應。
- 63 交易日：約一季；基本面與市場預期可能更重要。

優先輸出：上漲機率、相對基準超額報酬機率、10–90% 情境區間、風險因子、模型未確定性，以及「暫無優勢／不建議根據模型行動」。只有在回測與樣本外表現合格後才展示正式研究結果。

### 防止投資研究常見的錯誤
- **未來資訊洩漏：** 必須用資訊「首次公開且實際可取得」的時間建立特徵，不能用後來修正過的經濟數據假裝當時已知道。
- **倖存者偏誤：** 股市回測應保留已下市個股及歷史指數成分。
- **過度擬合：** 固定走勢基準，時間序列 walk-forward，保留最終樣本外期間。
- **不完整績效：** 計入稅費、手續費、滑價、外幣成本、期貨轉倉。
- **報酬／風險混淆：** 不因方向命中率高就稱能賺錢；需同時查看淨報酬、回撤、穩定性與概率校準。
- **來源授權：** 即時金融行情與歷史企業資料可能需要付費或特定授權，不能假設新聞網站資料可供商業模型自由抓取。

### 最早應建立的檢驗基準
1. 隨機方向／價格不變基準；
2. 買入持有與簡單動量；
3. 經濟／市場因子模型（例如風險溢酬、利率與產業動量）；
4. 加入新聞訊號後是否真的優於以上模型（**增量價值**）。

評估：方向準確率、Brier score、區間覆蓋率、收益風險比、最大回撤、扣費後績效及跨時段穩健性。若沒有顯著增量價值，只保留資訊分析，不對外聲稱具有預測能力。

## 七、部署及未完成項目
