# 視界 SIGNAL V0.5.0 — 每日選讀候選試刊（非正式全球日報）

## 這個版本改變什麼？

本版整合至「今日情報」頁面頂部。Github Actions 每次更新後，從現有經過權利與來源核准的標題元資料中，取出**最近 72 小時**且可追溯出處的候選，依發布時間並施加「最多 8 筆／同發布機構最多 2 筆／同分類最多 3 筆」限制，建立 `data/daily_brief_v050.json`。

每筆只有原文標題、發布時間、來源、連結、M0/M0A 標示及通用查核問題。**不會生成新聞內容摘要、全球重大性分數、獨立查證結果或投資預測**。資料不足時呈現不足，不拿老文章充當當日新聞。首頁既有 2026-11-05 編輯稿已標示為固定存檔。

**你重視的「可信與重要」目前只完成了前半部的來源與證據管理；本版在可用性上跨出第一步，並非品質宣稱。** 當前尚缺多家獨立新聞機構、台灣／日本／巴西等來源，亦沒有由人工核實的重大事件基準，因此不得宣稱全球新聞覆蓋率或實質的重要性辨識精度。

## Windows / GitHub Desktop 安裝

1. 在 GitHub Desktop 選擇 `signal-intelligence_V0.3.3`，先按 **Fetch origin → Pull origin**；若提示衝突，不要強制覆蓋。
2. 解壓縮更新包，**把 ZIP 內的檔案**（包含 `.github`）複製到原本 Repository 根目錄；同名檔案選「取代」，不要在外層再包一個資料夾。
3. 不需上傳或覆蓋 `data/live_items.json`、`data/intelligence.json` 等歷史資料：本更新包不含這些檔案。
4. GitHub Desktop Summary：`Pilot V0.5 daily review candidates with provenance gates`。按 **Commit to main → Push origin**。
5. GitHub 網頁 **Actions → SIGNAL V0.5.0 daily review candidates + Pages → Run workflow → main → Run workflow**。請使用新的一次執行，不要重跑舊版工作紀錄。
6. 看執行結果 `collect-build`、`deploy` 及 Summary 內的 **V0.5.0 每日情報「選讀候選」試刊**；再開首頁「今日情報」。

## 驗收標準

- 工作流程通過全部既有測試及新增 `scripts/test_v050.py`，成功發布 Pages。
- 自動公開的檔案新增 `data/daily_brief_v050.json`；資料完全來自現有來源白名單。
- 候選數量 **≤8**，跨發布機構去重與配額有效，原始出處能點開。
- 每筆均標示 **未查證**；M0A 只是核對作者摘要元資料，不得宣稱同儕審查或查證。
- 來源過期（48 小時無成功更新）顯示警示；72 小時沒有新資料時**顯示空狀態而非舊消息**。
- 既有 2026-11-05 靜態專題明確標示不是今日新報導。
- 不得包含第三方付費全文、未批准 RSS、交易建議、虛構摘要、AI 編造的重要性分數。

## 交付與限制

本版無須 OpenAI API，也不新增收費。程式已通過離線回歸測試及 JavaScript 語法檢查，但**尚未在你自己的 GitHub Action 進行 V0.5.0 的連網驗收**。

下一個核心驗收不是 UI，而是建立 **人工作成的 20–30 則重大事件基準**，對比 SIGNAL 的發現／漏報／誤選；另需合法接入獨立新聞與專業產業來源。驗證通過前，首頁只能稱為「選讀候選」，不能稱為完整新聞情報。
